# Рэндзю для Дианы — доставка

Полный Flutter-проект в репозитории https://github.com/ruDnepr/rendzu (ветка `main`).
APK для установки — в этой папке.

## APK

| Файл | Размер | Что это |
|---|---|---|
| `rendzu-release.apk` | ~23 МБ | **Релизная** сборка — оптимизированная, для проверки на телефоне |
| `rendzu-debug.apk` | ~73 МБ | Отладочная сборка — с инструментами разработчика |

**Качай `rendzu-release.apk`** — она меньше и быстрее. Установка: разрешить
«установку из неизвестных источников» и открыть APK на Android (minSdk 21 = Android 5.0+).

## Debug vs Release — в чём отличие

| | Debug | Release |
|---|---|---|
| Размер | ~73 МБ | ~23 МБ |
| Скорость | Медленнее (интерпретируемый Dart) | Быстрее (AOT-компиляция в нативный код) |
| Оптимизация | Нет | R8 (удаление неиспользуемого кода) + tree-shaking |
| Отладка | Да (логи, hot reload, debugger) | Нет |
| Подпись | Debug-ключ | Debug-ключ тут; для Google Play нужен свой keystore |
| Годится для | Разработки, тестов | Проверки на телефоне, распространения |

Release всегда меньше и быстрее за счёт AOT + R8 + обрезки иконок/шрифтов.

## Что сделано в этой версии

- **Тема унаследована от «Шашек для Дианы»**: фиолетово-кремовая палитра
  (ink/purple/cream/yellow/peach), шрифт Nunito, фон с мягкими «свечениями»,
  те же BigButton/ChoiceTile/PageFrame/showDianaDialog.
- **Камни не перекрываются**: радиус камня = 0.40×клетки, просвет между
  соседними = 0.2×клетки.
- **Диалог победы** показывает победный ход: «ходом №9 в (5,3) по горизонтали»
  + анимация-празднование + кнопки Играть снова / Отменить ход / В меню.
- **Иконка приложения**: пять камней по диагонали + победная жёлтая линия на
  фиолетовом фоне. Сгенерирована для Android/iOS/Web.
- **CI**: на каждый пуш собирает и debug, и release APK (артефакты 30 дней);
  на тег `v*` создаёт GitHub Release.

## Как пересобрать APK

```bash
cd /home/z/my-project   # или клонируй github.com/ruDnepr/rendzu
flutter pub get
flutter build apk --release    # → build/app/outputs/flutter-apk/app-release.apk
```

Или скачать готовый из GitHub Actions: https://github.com/ruDnepr/rendzu/actions →
последний run → Artifacts → `rendzu-release-apk`.
