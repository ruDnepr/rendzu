## Что сделано

- **Правила:** гомоку (5+ победа) и рэндзю (чёрные — ровно 5; запрещены 3-3,
  4-4, оверлайн; исключение — пять перекрывает запрет). Полностью покрыто тестами.
- **ИИ:** 3 уровня — лёгкий (эвристика + случайность), средний (глубина 2),
  сложный (минимакс + альфа-бета, глубина 4). ИИ не делает запрещённых ходов.
- **Режимы:** против компьютера, два игрока, сеть (WebSocket + mDNS, код 6 символов).
- **UI:** заставка, меню, правила, настройки, игровой экран с 3D-доской
  (Transform+Matrix4), объёмными камнями с бликом, подсказками, подсветкой
  паттернов и победной линии. Тёплая палитра как в «Шашках для Дианы».
- **Отмена хода** офлайн и по согласию в сети; **сдача**; **подсказки**.

Структуру, архитектуру и список тестов см. в корневом `README.md`.
