# Рэндзю для Дианы 🎲

Детская мобильная игра «пять в ряд» (гомоку и рэндзю) на Flutter — для ребёнка 9 лет.
Два набора правил, доски 9×9 и 15×15, игра против компьютера (3 уровня), два игрока
на одном устройстве и сетевая игра по локальной Wi-Fi сети.

## Возможности

- **Два набора правил:**
  - **Гомоку** — свободное пять в ряд, без запрещённых ходов (по умолчанию).
  - **Рэндзю** — для чёрных есть запрещённые ходы: двойное три (3-3), двойное
    четыре (4-4), оверлайн (6+). Чёрные побеждают только ровно пятью; белые —
    пятью и более. Исключение: если запрещённый ход одновременно строит ровно
    пять — это победа чёрных.
- **Размер доски:** 9×9 (для начинающих) и 15×15 (стандарт рэндзю).
- **Режимы:**
  - Против компьютера — три уровня (лёгкий / средний / сложный с минимаксом и
    альфа-бета). ИИ **никогда** не делает запрещённых ходов в рэндзю.
  - Два игрока на одном устройстве.
  - По локальной сети (WebSocket + mDNS) с коротким кодом подключения.
- **Помощь:** подсветка возможных ходов, троек и четвёрок, предупреждение о
  запрещённом ходе с детским пояснением, кнопка «Подсказка».
- **Отмена хода** в офлайне; в сети — по согласию (запрос/ответ).
- **Оформление:** тёплая деревянная доска, объёмные камни с бликом и тенью,
  лёгкий 3D-наклон, плавные анимации постановки, звёздные точки как в го.
- **Настройки:** правила, размер доски, уровень ИИ, цвет, подсказки, звук, имя.

## Запуск

```bash
flutter pub get
flutter run                 # на подключённом устройстве/эмуляторе
flutter test                # 74 теста
flutter analyze             # без ошибок и предупреждений
flutter build apk --release # сборка Android
```

> Требуется Flutter ≥ 3.22 / Dart ≥ 3.4. Проект сгенерирован на Flutter 3.24.5.

## Сетевая игра

Хост поднимает WebSocket-сервер (shelf_web_socket) и регистрируется через mDNS
(nsd), показывая короткий код из 6 символов (без `0/O/1/I/l`). Клиент вводит
код или IP:порт. Протокол JSON: `hello`, `lobby`, `gameConfig`, `move`,
`forbiddenWarning`, `win`, `undoRequest`, `undoResponse`, `resign`, `ping/pong`.
Хост — авторитет: отклоняет запрещённые ходы и рассылает `forbiddenWarning`.

## Тесты (74)

- `pattern_detector_test` — серии, четвёрки (включая двойное-четыре на одной
  линии), открытые тройки, открытые четвёрки.
- `renju_forbidden_checker_test` — оверлайн, 3-3, 4-4, исключение (пять
  перекрывает запрет), `forbiddenMoves`.
- `game_rules_test` — гомоку (5 и 6+ = победа, ничья), рэндзю (чёрные ровно 5,
  оверлайн не победа, белые 5+, белые без запретов).
- `game_state_test` — поток игры, победа, отклонение запрещённого хода, отмена,
  подсказка, сдача.
- `renju_ai_test` — завершает пять, блокирует угрозу, не делает запрещённых
  ходов, избегает оверлайна.
- `network_message_test` — round-trip всех сообщений, код подключения.
- `board_widget_test` — рендеринг, камни, тап по пересечению, маркеры.
- `widget_test` — дымовой тест приложения.

## Детские упрощения

- Запрещённые ходы **не дают сделать** (с пояснением) — ребёнок не проигрывает
  случайно. В строгом рэндзю запрещённый ход = поражение; здесь — мягкий режим.
- Гомоку и доска 9×9 по умолчанию.
- Подсказки и подсветка паттернов включены изначально.
